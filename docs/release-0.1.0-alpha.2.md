## CS2 IP Changer 0.1.0-alpha.2

ServerRouteTool has a new name and the app is in English now. It works the same as before: CS2 and Steam go through your phone's mobile data, so community servers never see your home IP, and you can change that IP when you get IP banned.

This is still an alpha. If something breaks your connection, Settings > Restore network undoes everything.

### Getting started
1. Download `CS2IPChanger.exe` below and put it in its own folder.
2. Plug in your Android phone by USB, turn on USB tethering and turn off the phone's Wi-Fi.
3. Run the app as admin and paste your servers into Servers.

### Coming from 0.1.0-alpha.1
Drop `CS2IPChanger.exe` into the same folder as `ServerRouteTool.exe`. It uses the same `SRT_Dados` folder, so your servers, accounts and settings are still there.

### What changed
- New name: CS2 IP Changer.
- The interface, logs and checks are all in English.
- New README.

Requirements: Windows 10/11 64-bit, admin rights, an Android phone with USB tethering. The exe includes .NET, so there's nothing else to install.
