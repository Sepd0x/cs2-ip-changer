## ServerRouteTool 0.1.0-alpha.1

First public release. IP ban bypass and home IP protection for CS2 community servers: servers see the IP of the phone's mobile data, never your home IP.

Alpha: it works, but it may have bugs. If something goes wrong, Settings > Restore network undoes everything.

### Getting started
1. Download `ServerRouteTool.exe` below and put it in its own folder.
2. Plug in your Android phone by USB, turn on USB tethering and turn off the phone's Wi-Fi.
3. Run the app as admin and paste your servers into Servers.

### What's in it
- Game only, whole PC while CS2 is open, or whole PC always through the phone.
- Windows Firewall kill switch and CS2 locked to the phone.
- Change IP over ADB, IP history and a leak test.
- Server list with map, players and ping.
- Steam account switcher with bans and cooldowns.

Requirements: Windows 10/11 64-bit, admin rights, an Android phone with USB tethering. The exe includes .NET.

Full list of changes in the repository's `CHANGELOG.md`.
