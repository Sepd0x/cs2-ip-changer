## ServerRouteTool 0.1.0-alpha.1

Primeira versão pública. IP ban bypass e proteção do IP de casa para servidores comunitários do CS2: os servidores veem o IP dos dados móveis do telemóvel, nunca o de casa.

**Alpha:** funciona, mas pode ter erros. Se algo correr mal, Definições > Restaurar rede desfaz tudo.

### Como começar
1. Descarrega o `ServerRouteTool.exe` abaixo e põe-no numa pasta só dele.
2. Liga o telemóvel Android por USB, liga o Tethering USB e desliga o Wi-Fi do telemóvel.
3. Abre a app como administrador e cola os teus servidores em Servidores.

### O que traz
- Só o jogo, tudo com o CS2 aberto, ou tudo sempre pelo telemóvel.
- Kill switch na Firewall do Windows e CS2 trancado ao telemóvel.
- Trocar IP por ADB, histórico de IPs e teste de fugas.
- Lista de servidores com mapa, jogadores e ping.
- Troca de contas Steam com bans e cooldowns.

Requisitos: Windows 10/11 64 bits, administrador, telemóvel Android com Tethering USB. O `.exe` já traz o .NET.
