CS2 IP Changer or a VPN? Both change the IP a server sees.

Many community servers block VPNs; a phone's mobile data looks like any player on a hotspot.

Why a phone's IP is different

Carriers share each IP between many phones (CGNAT), so blocking one IP can block many real players. It's not a promise: an IP someone else misused can still be flagged, and Change IP gets you another one.

Source: IPHub on shared (CGNAT) addresses

Why servers block VPNs

To stop banned players coming back, many community servers run an anti-VPN plugin. It looks up each player's IP in a list of VPN and datacenter addresses. One CS2 plugin's default answer to a VPN is a ban, not a kick.

Setup. One cable, four steps.

Windows 10 or 11 (64-bit), admin rights, Windows Firewall on, and a phone with mobile data.

  1. Download CS2IPChanger.exe from the latest release. Started from Downloads, it offers to install itself in C:\Program Files\CS2 IP Changer in one click.
  2. Plug the phone in by USB, turn on USB tethering (Personal Hotspot on an iPhone) and turn off the phone's Wi-Fi. Using a VPN on the PC? Turn it off first.
  3. Run the app as admin. Phone setup shows each step in green or red and what's missing. Paste the servers you play on into Servers (the IP:port from CS2's console, status), then press Turn on protection: it starts off each time the app opens.
  4. Open Connection. With CS2 and Steam running, every check should be green, including Phone IP is not your home IP.

FAQ. The short answers.

Is it a VPN? Does it work on servers that block VPNs?

It isn't a VPN. A VPN sends your traffic through a datacenter, and many community servers run anti-VPN plugins that kick or ban datacenter and VPN IPs. This app sends CS2 and Steam through your own phone's mobile data, so the server sees an ordinary mobile connection from your carrier, and it usually gets in where a VPN doesn't. Not a promise: carriers share IPs between many phones, so an IP someone else misused can be flagged; Change IP gets you another one. There's no VPN server in between and no subscription.

What do I need?

Windows 10 or 11 (64-bit), admin rights, Windows Firewall turned on, and an Android phone or iPhone with mobile data, connected by USB cable (USB tethering, or Personal Hotspot on an iPhone) or its Wi-Fi hotspot. Change IP from the PC needs an Android phone with USB debugging on; on an iPhone you switch Airplane Mode on and off yourself. CS2 and Steam then use the phone's data plan.

Does it work with an iPhone?

Yes, the protection does: an iPhone's USB tethering (Personal Hotspot) shows up in Windows like an Android one, and so does its Wi-Fi hotspot. Change IP from the PC needs ADB, which only Android has, so on an iPhone you get a new IP by switching Airplane Mode on and off on the phone.

Can it get me VAC banned? Does it need my Steam password?

It never touches the game: not cs2.exe, its memory or its program files. It changes Windows routes and firewall rules, and which saved Steam account logs in. Switching accounts uses the logins Steam already saved and never asks for your Steam password. It won't hide a cheat from VAC or any anti-cheat, and we can't speak for Valve or for a server's admins, who set their own rules.

Does it send anything about me?

While the app is in beta it sends usage stats, which are required to use it: the first start shows what is sent, with Accept and Quit (Quit closes the app without changing anything). It sends them when the app has been open for 20 seconds, every 30 minutes while it stays open and when it closes, with a short signal every 5 minutes of what is on: a random ID made for this install, with no name (never from your PC or from you; Settings > Delete my stats deletes it all), versions, your country, the mode, how the phone is connected, minutes open, how often each button is used, a few counters, how long your lists are and errors. Never IPs, servers, accounts, names or anything you typed, and the server keeps no IP. The full list is in the README.
