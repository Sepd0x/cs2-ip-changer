How it works

It isn't a VPN. The server sees an ordinary mobile connection from your carrier, so it also works on community servers that block VPNs and datacenter IPs.

  1. Plug in the phone USB tethering or its hotspot shares the phone's mobile data with the PC.
  2. Only the game moves CS2, Steam and your servers use the phone. Browser, Discord and downloads stay at home.
  3. Nothing falls back Once a phone has been connected, a pulled cable cuts CS2 off instead of using your home IP.

Setup

Windows 10 or 11 (64-bit), admin rights, Windows Firewall on, and an Android phone with mobile data.

  1. Download CS2IPChanger.exe from the latest release into a folder only admins can change, like C:\Program Files\CS2 IP Changer.
  2. Plug the phone in by USB, turn on USB tethering and turn off the phone's Wi-Fi. Phone setup tells you what's missing.
  3. Run the app as admin and paste the servers you play on into Servers.
  4. Open Connection. With CS2 and Steam running, every check should be green and the IP servers see must not be your home IP.

Change IP also needs USB debugging on the phone. Settings > Turn off protection undoes it all. Full walkthrough: Change IP with your phone.

FAQ

Is it a VPN? Does it work on servers that block VPNs?

No, it isn't a VPN, and yes, it works there. A VPN sends your traffic through a datacenter, and many community servers block datacenter and VPN IP ranges. This app sends CS2 and Steam through your own phone's mobile data, so the server sees an ordinary mobile connection from your carrier. There's no VPN server in between and no subscription.

What do I need?

Windows 10 or 11 (64-bit), admin rights, Windows Firewall turned on, and an Android phone with mobile data, connected by USB cable (USB tethering) or its Wi-Fi hotspot. USB debugging on the phone is only needed to change IP from the PC. CS2 and Steam then use the phone's data plan.

Can I use the phone's Wi-Fi hotspot instead of a cable?

Yes. Connect the PC to the hotspot and pick it under Connection > How the PC connects to the phone. The app remembers the network name, and if Windows jumps back to your home router it blocks everything. Change IP works on the hotspot too if the phone is also plugged in by USB with USB debugging on.

Does it send anything about me?

While the app is in beta it sends anonymous usage stats, once when it has been open for 20 seconds and then once a day: a random install ID, versions, your country, the mode, minutes open and how often each button is used. Never IPs, servers, accounts, names or anything you typed, and the server keeps no IP. The full list is in the README.
