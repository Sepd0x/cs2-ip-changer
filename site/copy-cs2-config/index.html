Where CS2 keeps each account's config

CS2 saves settings per Steam account in Steam\userdata\<id>\730\local\cfg:

  • binds in cs2_user_keys_0_slot0.vcfg
  • crosshair and game settings in cs2_user_convars_0_slot0.vcfg
  • video in cs2_video.txt
  • HUD, radar and audio in cs2_machine_convars.vcfg

Copying these by hand works, but it's easy to copy the wrong folder, and Steam Cloud can bring the old files back. The app writes the same files CS2 writes when you change a setting, and never the game itself (what it changes).

What the Configs page does

  • Pick what to copy: binds, crosshair, the other game settings (sensitivity, viewmodel), video, and HUD, radar and audio, each on its own. You can copy only the crosshair and keep each account's sensitivity.
  • Sync modes: from a main account, from the account you used before, or latest change wins. It runs when a new account shows up, before the app logs in or opens CS2, or when you click Sync now.
  • Never with CS2 open. CS2 saves its config when it closes and would undo the copy, so the copy waits until it closes.
  • Steam Cloud too. The app writes the cloud copy the same way CS2 does, so Steam uploads the new one on the next launch.
  • Backups and undo. Every change keeps a backup (the 20 newest per account), and Undo last sync puts it all back.
  • Snapshots and compare. Save a config under a name, export it as a .zip for another PC, and compare two accounts setting by setting with a crosshair preview.
  • Video stays this PC's. Each account keeps this PC's refresh rate and monitor, so a 144 Hz screen doesn't end up at 60 Hz.

FAQ

Can't I just use the crosshair share code?

The share code only moves the crosshair. Your binds, sensitivity, viewmodel, video, HUD, radar and audio stay behind, and you have to paste it on every account. The Configs page copies all of it, or only the parts you tick, to every account at once.

My settings keep going back. Why?

Steam Cloud. If an account was played on another PC since, Steam may bring that version back or ask which one to keep. If it keeps happening, turn off Steam Cloud for CS2 (CS2 > Properties > General).

Can I move my config to another PC?

Yes. Save a snapshot and export it as a .zip. The .zip only has the config files and the name, never the account.
