Кто видит ваш IP

  • Админы комьюнити-серверов и их плагины. Игровой трафик CS2 идёт по UDP напрямую между вашим ПК и сервером, и серверу нужен адрес, чтобы отправлять пакеты обратно. Тот, кто держит сервер, видит и может логировать этот адрес, а его админ-инструменты работают по нему.
  • Официальный матчмейкинг не в счёт. Матчмейкинг Valve идёт через Steam Datagram Relay, поэтому другие игроки там не получают ваш IP.

Что они могут с ним сделать

  • Забанить его. Бан по IP касается всех аккаунтов, с которых вы играете через это соединение, а некоторые админы банят целый диапазон (как работают баны).
  • Определить, где вы. По IP видно вашего провайдера и примерное местоположение.
  • Атаковать его. DDoS бьёт по IP. С домашним IP это ваше домашнее соединение.

Почему мобильный интернет

Сервер видит обычное мобильное соединение вашего оператора, а не дата-центр, поэтому обычно проходит мимо anti-VPN плагинов. Если играть через точку доступа телефона вручную, получится то же самое. Работает с Android и iPhone (на iPhone новый IP даёт Airplane Mode: CS2 с iPhone). Приложение добавляет то, что вручную сложно: телефон используется только игрой, kill switch держит её на нём, если выдернуть кабель, живые проверки и тест на утечки показывают IP, который видят серверы, а Change IP даёт новый. FAQ

Показывает ли официальный матчмейкинг мой IP?

Матчмейкинг Valve идёт через Steam Datagram Relay, поэтому другие игроки там не получают ваш IP. Его видят комьюнити-серверы, на которые вы заходите напрямую.

Видит ли админ комьюнити-сервера мой IP?

Да. Серверу нужен ваш IP, чтобы слать игровые пакеты, поэтому админы и их плагины могут его видеть, логировать и банить. С мобильным интернетом телефона они получают IP вашего оператора.

Что делает cl_hideserverip?

Это консольная настройка для стримеров: с cl_hideserverip 1 CS2 скрывает на вашем экране IP сервера, на котором вы играете (консоль и status), чтобы зрители его не видели. Ваш IP она не скрывает: сервер всё равно видит ваш домашний IP. Чтобы скрыть его, сервер должен видеть другое соединение, например мобильный интернет вашего телефона.
