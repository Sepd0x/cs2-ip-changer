Is CS2 IP Changer safe?

A tool that asks for admin and changes your network should explain itself. Here is what CS2 IP Changer changes on your PC, what it never touches, and how you can check every release yourself.

What it changes, and what it never touches

  • Changes: Windows routes and Windows Firewall rules (all named with the app's prefix), which saved Steam account logs in, and, only if you use those pages, CS2's config files and your Steam profiles.
  • Never touches: the game process, its memory or its program files. It hides nothing from VAC or any anti-cheat.
  • Why admin: routes and firewall rules are system settings, and Windows only lets admins change them. Steam, CS2, your browser and the programs it opens for you still run as you, not as admin.

Check your download

  • Every release is built by GitHub Actions from the public source and comes with a build attestation. With the GitHub CLI: gh attestation verify CS2IPChanger.exe -R Sepd0x/cs2-ip-changer.
  • Each exe has a SHA-256 file next to it in the release. In PowerShell: Get-FileHash .\CS2IPChanger.exe, and compare.
  • Signed updates. The app only installs an update whose SHA-256 is signed with the project's key, which is not on GitHub.
  • The exe isn't code-signed yet, so Windows SmartScreen may warn the first time. More info > Run anyway.

Your data

  • No account, and no passwords kept. The account switcher uses the logins Steam already saved.
  • While the app is in beta it sends anonymous usage stats once a day: a random install ID, versions, your country, the mode, minutes open and button counts. Never IPs, servers, accounts or names. The server code is public (worker/stats).
  • Save bug report strips your home IP, logins, names and SteamIDs before you send anything.

Undo everything

Turn off protection (Settings > Maintenance) removes the routes and the kill switch, and Allow all on the Regions page lifts the region block. To remove everything at once, run CS2IPChanger.exe --restore (or tools/restore.cmd from the repo): every route and firewall rule the app made is removed. The app is portable: to uninstall, run --restore, then delete its folder (with SRT_Dados next to the exe) and C:\ProgramData\CS2IPChanger.

FAQ

Is it open source?

The source is public on GitHub so anyone can read and build it, but the license is All rights reserved during the beta: you can use the releases, not copy or redistribute the code.

Can this get me VAC banned?

It never touches the game process, its memory or its program files. It changes Windows routing and firewall rules and which Steam account logs in.

Why does my antivirus complain?

The exe is not code-signed and it changes firewall rules and runs ADB, which some antivirus engines flag on heuristics alone. Check the attestation and SHA-256 above; if a detection looks wrong, open an issue.
