What it changes, and what it never touches

  • Changes: Windows routes and Windows Firewall rules (all named with the app's prefix), which saved Steam account logs in, and, only if you use those pages, CS2's config files and your Steam profiles.
  • Never touches: the game process, its memory or its program files. It hides nothing from VAC or any anti-cheat.
  • Why admin: routes and firewall rules are system settings, and Windows only lets admins change them. Steam, CS2, your browser and the programs it opens for you still run as you, not as admin.

Check your download

  • Every release is built by GitHub Actions from the public source and comes with a build attestation. With the GitHub CLI: gh attestation verify CS2IPChanger.exe -R Sepd0x/cs2-ip-changer.
  • Each exe has a SHA-256 file next to it in the release. In PowerShell: Get-FileHash .\CS2IPChanger.exe, and compare.
  • Signed updates. The app only installs an update whose SHA-256 matches the release and is signed with the project's offline key, with the version inside so an old release can't come back under a new tag. The key isn't on GitHub, so access to the repo alone can't push an exe to installed copies.
  • VirusTotal for each release: 0 of 68 engines flag beta.10 (SHA-256 fae35fdfe338…, the same as its .sha256 file).
  • The exe isn't code-signed, so Windows SmartScreen may warn the first time. More info > Run anyway.

Your data

  • No account, and no passwords kept. The account switcher uses the logins Steam already saved.
  • Usage stats, required to use the app in the beta: the first start shows what is sent, with Accept and Quit (Quit closes the app without changing anything). Then once when it has been open for 20 seconds, when it closes and once a day: a random ID made for this install, with no name (Settings > Delete my stats deletes everything kept under it), versions, your country, the mode, how the phone is connected, minutes open, button counts, where on each screen people click (a coarse grid, added up with everyone, with no ID), a few counters, list sizes and errors, and in rough bands how long ago the app was set up, each CS2 match's ping, jitter and lag (never the server), session length and crashes. Once a day a separate report with no ID and no country says the Windows language, window and screen scale, the Windows build, the phone's brand (never the model), Android version and 4G or 5G, and is only added into counts. Never IPs, servers, accounts or names. The server code is public (worker/stats).
  • Who keeps them: the author of this project (Sepd0x on GitHub), only to find and fix bugs and make the app better, never sold or shared. The basis is that you accept the notice. They are stored on Cloudflare, which processes them for the project. Rows with an ID are deleted after 12 months; counts with no ID stay. Delete my stats deletes yours at once; for anything else, open an issue on GitHub, or complain to your data protection authority.
  • This website counts visits and clicks on Download with no cookies and no ID: the page, the name of the site you came from and the country, only as counts per day. With Do Not Track or Global Privacy Control on, it sends nothing. GitHub Pages, which hosts it, keeps its own logs.
  • To show the carrier and city, the app asks ipwho.is about your home IP and the phone's IP, so ipwho.is receives both, each one only through its own connection. Your public IP is measured with ipify, icanhazip, Amazon and Cloudflare. The full list, and what the app does with admin rights: Privacy and security.
  • Save bug report saves a .zip on your Desktop and sends nothing. It leaves out your current and last home IP, API key, logins, names, SteamIDs, e-mails, Wi-Fi names and your Windows user; look through it before you post it.

Undo everything

Turn off protection (on the Connection page, or in the icon's menu next to the clock) removes the routes and the kill switch, and Allow all (block off) on the Regions page lifts the region block. To remove everything at once, run CS2IPChanger.exe --restore (or tools/restore.cmd from the repo): every route and firewall rule the app made is removed. To uninstall, use Uninstall in Windows Settings > Installed apps, or Remove CS2 IP Changer at the bottom of Settings: it removes the rules, routes, the Start with Windows task, C:\ProgramData\CS2IPChanger and the app, and you pick whether SRT_Dados (settings and accounts) stays.

FAQ

Can this get me VAC banned?

It never touches the game process, its memory or its program files. It changes Windows routing and firewall rules and which Steam account logs in. If you use them, the Configs page copies CS2's config files between your accounts and the Profiles page changes your Steam profiles. It also won't hide a cheat from VAC or any other anti-cheat, so don't use it for that.

Is it open source?

The source is public on GitHub so anyone can read and build it, but the license is All rights reserved during the beta: you can use the releases, not copy or redistribute the code.

Why does my antivirus complain?

The exe is not code-signed and it changes firewall rules and runs ADB, which some antivirus engines flag on heuristics alone. Check the attestation and SHA-256 above; if a detection looks wrong, open an issue.
