What it changes, and what it never touches

  • Changes: Windows routes and Windows Firewall rules (all named with the app's prefix), which saved Steam account logs in, and, only if you use those pages, CS2's config files and your Steam profiles.
  • Never touches: the game process, its memory or its program files. It hides nothing from VAC or any anti-cheat.
  • Why admin: routes and firewall rules are system settings, and Windows only lets admins change them. Steam, CS2, your browser and the programs it opens for you still run as you, not as admin.

Check your download

  • Every release is built by GitHub Actions from the public source and comes with a build attestation. With the GitHub CLI: gh attestation verify CS2IPChanger.exe -R Sepd0x/cs2-ip-changer.
  • Each exe has a SHA-256 file next to it in the release. In PowerShell: Get-FileHash .\CS2IPChanger.exe, and compare.
  • Signed updates. The app only installs an update whose SHA-256 matches the release and is signed with the project's offline key, with the version inside so an old release can't come back under a new tag. The key isn't on GitHub, so access to the repo alone can't push an exe to installed copies.
  • VirusTotal for each release: 0 of 70 engines flag beta.7.
  • The exe isn't code-signed, so Windows SmartScreen may warn the first time. More info > Run anyway.

Your data

  • No account, and no passwords kept. The account switcher uses the logins Steam already saved.
  • While the app is in beta it sends anonymous usage stats once when it has been open for 20 seconds, then once a day: a random install ID, versions, your country, the mode, minutes open and button counts. Never IPs, servers, accounts or names. The server code is public (worker/stats).
  • Save bug report saves a .zip on your Desktop and sends nothing. It leaves out your home IP, API key, logins, names, SteamIDs, e-mails, Wi-Fi names and your Windows user; look through it before you post it.

Undo everything

Turn off protection (on the Connection page, or Settings > Undo and maintenance) removes the routes and the kill switch, and Allow all (block off) on the Regions page lifts the region block. To remove everything at once, run CS2IPChanger.exe --restore (or tools/restore.cmd from the repo): every route and firewall rule the app made is removed. The app is portable: to uninstall, run --restore, then delete its folder (with SRT_Dados next to the exe) and C:\ProgramData\CS2IPChanger.

FAQ

Can this get me VAC banned?

It never touches the game process, its memory or its program files. It changes Windows routing and firewall rules and which Steam account logs in. If you use them, the Configs page copies CS2's config files between your accounts and the Profiles page changes your Steam profiles. It also won't hide a cheat from VAC or any other anti-cheat, so don't use it for that.

Is it open source?

The source is public on GitHub so anyone can read and build it, but the license is All rights reserved during the beta: you can use the releases, not copy or redistribute the code.

Why does my antivirus complain?

The exe is not code-signed and it changes firewall rules and runs ADB, which some antivirus engines flag on heuristics alone. Check the attestation and SHA-256 above; if a detection looks wrong, open an issue.
