# Contributing

Thanks for wanting to help. CS2 IP Changer is in beta, and the most useful thing right now is a good bug report.

## Reporting a bug
[Open an issue](https://github.com/Sepd0x/cs2-ip-changer/issues/new/choose) with the bug template and add:
- the version (bottom left of the window);
- what you did, what you expected and what happened;
- the diagnostics: Log tab > Export diagnostics saves a .zip on your Desktop. Your home IP, logins and API key are left out, but look through it before you post.

If you paste the log instead (Copy all), blank out your IPs first.

## Ideas
Use the feature request template. Say what you want to do in the game, not only the button you'd add: there may be a simpler way.

## Security problems
Don't open a public issue. Follow [SECURITY.md](.github/SECURITY.md).

## Code
The source is public so you can see what the app does to your PC, but it isn't open source (see [LICENSE](LICENSE)). Pull requests aren't accepted for now. If you found a fix, describe it in an issue.
